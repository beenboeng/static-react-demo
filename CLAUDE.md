# static-react-app-demo

Client-side SPA built with TanStack Router (file-based routing), React 19, Vite, Tailwind v4.
Not TanStack Start — there is no server, no server functions, no API routes.

## Commands

```bash
bun install
bun --bun run dev      # http://localhost:3000
bun --bun run build
bun --bun run preview
```

## Where things go

| What | Where | Notes |
|---|---|---|
| Reusable components | `src/components/` | One component per file, PascalCase filename matching the export (`UserTable.tsx` → `UserTable`) |
| Pages / routes | `src/routes/` | File-based; the filename *is* the URL |
| Root layout | `src/routes/__root.tsx` | Wraps every route |
| Custom hooks | `src/hooks/` | `useThing.ts`, camelCase |
| Page content / copy | `src/data/site.ts` | Section content lives here as typed arrays, not inline in JSX |
| Shared types | `src/types/` | Prefer non-optional fields |
| Global styles | `src/styles.css` | Tailwind v4 is CSS-first — no `tailwind.config.js` |

When designing or adding UI, put presentational pieces in `src/components/` and keep
`src/routes/*` files thin — they compose components and own data loading, not markup.

## Components: use HeroUI

Build all UI from **HeroUI** (`@heroui/react`) components — Button, Input, Table, Modal,
Card, Chip, Pagination, etc. Do not hand-roll a component when HeroUI ships one.
Drop to a plain element only for layout (`div`, `section`) or when no HeroUI equivalent exists.

The `heroui-migration` MCP server is configured in `.mcp.json`. Consult it for HeroUI
component APIs, prop names, and import paths instead of guessing from memory.

Import individually from the package root:

```tsx
import { Button, Input, Modal } from '@heroui/react'
```

## Rules

- **Never edit `src/routeTree.gen.ts`** — it is generated by the Vite plugin on dev/build.
  Add a route by creating a file in `src/routes/`; run `bun run generate-routes` to regenerate manually.
- Import from `src/` with the `#/*` alias (e.g. `import { Button } from '#/components/Button'`).
  `@/*` is also mapped in tsconfig but `#/*` is the one declared in package.json — prefer it.
- Style with Tailwind utility classes. No CSS modules, no styled-components.
- TypeScript is strict, with `noUnusedLocals` and `noUnusedParameters` on — dead variables fail the build.

## Context

This folder is a standalone demo inside the `host_porject` DevOps-class monorepo.
The sibling `../ui/` (HeroUI + TanStack Query) and `../api/` (Go + Echo) are a separate
user-management app — this demo does not talk to that API.
